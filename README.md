## How to deploy and upgrade

To deploy `TaexNFT` contract on Sepolia Testnet:

`npx hardhat run scripts/deployTaexNFT.js --network sepolia`

To deploy `TaexNFT1155` contract on Sepolia Testnet:

`npx hardhat run scripts/deployTaexNFT1155.js --network sepolia`

To deploy `SaleNFT` contract on Sepolia Testnet:

`npx hardhat run scripts/deploySaleNFT.js --network sepolia`
